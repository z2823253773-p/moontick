# 中断、换会话或换机器后的恢复指令

```text
继续 MoonTick，不要从头重新规划。若产品仓库尚不存在，先读 MoonTick-季度参赛方案-v1.1 的 00、08、10 和状态模板，继续当前规划/工具链任务，不在父目录运行 Git 写入。仓库已存在时读 AGENTS.md、.ai/TASK_STATE.md、当前任务卡和相关规格。

只读核对 git status、分支、最新 commit 与交接是否一致，检查本机 Moon 工具链。有未知未提交改动时保留并确定归属，不 reset/clean。说明本轮是实现者还是验证者、是否拥有当前 checkout 写入权。

用五行以内汇报：当前步骤、上次确实完成什么、仍欠什么证据、下一动作、是否存在必须由我决定的问题。然后继续已有授权范围内的当前任务。

不得把另一台机器的通过当成本机验证。不得把 dry-run、源码测试、发布包安装和官方验收混为一谈。结束前更新磁盘状态，留下下一位可直接执行的动作。
```
