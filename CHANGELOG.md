# Changelog

## 0.1.0 — 2026-09-22

- Audit a caller-declared half-open, fixed-step Int64 millisecond grid without enumerating its expected points.
- Report coverage, compressed missing ranges, duplicate rows, out-of-order rows, off-grid rows, and out-of-range rows through a MoonBit library and native CLI.
- Read strict one-timestamp-per-line ticks files; render stable text and JSON reports with precise exit codes and input locations.
- Add synthetic examples, independently enumerated oracle checks, native process tests, and pinned macOS arm64/Linux x86_64 GitHub Actions.

Published on [Mooncakes](https://mooncakes.io/docs/z2823253773-p/moontick@0.1.0) from the [v0.1.0 source tag](https://github.com/z2823253773-p/moontick/tree/v0.1.0). The uploaded 0.1.0 archive is immutable and retains a pre-release status sentence in its README; this repository's README now reflects the verified release.
